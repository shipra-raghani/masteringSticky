The Sticky Concept

Sticky positioning allows an element to remain visible while you scroll through a page. It combines normal document flow with fixed positioning.

Crucially, a sticky element only stays within its parent container. Once the parent container scrolls out of view, the sticky element goes with it

To make an element sticky, you need two things:

  • position: sticky;
  • An edge offset like top,bottom left or right.
